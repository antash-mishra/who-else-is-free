What changed

Exact, purposeful copy

Signed-out users see “Your plans are waiting” and the requested invitation to get started. Signed-in hosts see “Your hosted plans will appear here.”

Honest load-state precedence

My Plans renders initial loading, then an uncached error with retry, then genuine tab content. Cached event lists stay visible through later refreshes and failures.

One shared presentation

New EventListLoadState owns the spinner, accessible error icon, message, and shared AppButton. Discover now consumes it too.

Middle-dot regression protected

Production already used the shared separator. Stale assertions were corrected and now cover both location/time and compact audience metadata.

Device: Android 16 emulator WEIF_API_36, 1080 × 2400. The emulator UI bridge became unresponsive while forcing the backend-offline screenshot. No ambiguous frame is included; the loading, error, retry, and cached-content branches are instead covered by deterministic focused tests.
