Empty states now align consistently

My Events and Chat previously positioned some empty states inside content-height wrappers, leaving them visibly too high. The affected signed-out and signed-in paths now fill their available content area and center the illustration-and-copy group consistently.

✓ Verified fixed while signed out and signed in

Reported state

Fixed states

Exact issue and root cause

The shared EmptyState intentionally sizes to its content. Full-screen callers must therefore provide the available height. Discover and signed-in My Events already did this through EventSectionList; signed-out My Events, signed-out Chat, and the signed-in Chat FlatList empty component did not. Those three paths consequently used intrinsic height and were top-biased.

The fix is deliberately scoped to those full-screen call sites: each passes a flex: 1 style to EmptyState. This preserves compact empty states in sheets and cards while restoring full-height centering where the screen owns the space. 

<EmptyState
  ...
  style={styles.fillEmptyState}
/>

fillEmptyState: { flex: 1 }
